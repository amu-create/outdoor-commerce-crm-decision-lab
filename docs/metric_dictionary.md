# Metric dictionary

모든 시간 집계는 `orders.created_at`, 기준일 `2026-08-07`을 사용한다. 아래 7개는 현재 SQL 또는 실사 결과에서 실제 산출 중인 지표만 기록한다.

## 1. 순매출

- 사업 정의: 취소·반품되지 않은 주문 품목의 판매금액.
- SQL 정의: `SUM(IF(order_status NOT IN ('Cancelled', 'Returned'), sale_price, 0))`.
- 날짜 기준: `orders.created_at`의 주문월.
- 포함·제외 상태: `Cancelled`, `Returned` 제외; 나머지 상태 포함.
- 분자·분모: 분자만 존재하며 포함 품목의 `sale_price` 합계.
- 단위: 원천 데이터 통화 금액.
- 반올림: CSV 소수 둘째 자리, 사업 문서 정수.
- 한계: 할인 `0/180,066개`; 환율·세금·물류비는 반영하지 않음.

## 2. 총매출

- 사업 정의: 주문 상태와 무관한 전체 주문 품목 판매금액.
- SQL 정의: `SUM(sale_price)`.
- 날짜 기준: `orders.created_at`의 주문월.
- 포함·제외 상태: 모든 주문 상태 포함.
- 분자·분모: 분자만 존재하며 전체 품목의 `sale_price` 합계.
- 단위: 원천 데이터 통화 금액.
- 반올림: CSV 소수 둘째 자리, 사업 문서 정수.
- 한계: 취소·반품 금액도 포함하므로 실현 매출로 해석하지 않음.

## 3. AOV

- 사업 정의: 취소·반품 제외 주문 1건당 순매출.
- SQL 정의: `SAFE_DIVIDE(net_revenue, valid_order_count)`.
- 날짜 기준: `orders.created_at`의 주문월.
- 포함·제외 상태: 분자와 주문수 모두 `Cancelled`, `Returned` 제외.
- 분자·분모: 순매출 / 유효 주문수.
- 단위: 주문당 원천 데이터 통화 금액.
- 반올림: CSV 소수 둘째 자리, 사업 문서 정수.
- 한계: 고객당 구매 품목 수와 상품 구성 변화가 함께 반영됨.

## 4. 마진

- 사업 정의: 취소·반품 제외 판매금액에서 상품 원가를 차감한 금액.
- SQL 정의: `SUM(IF(valid_status, sale_price - cost, 0))`.
- 날짜 기준: `orders.created_at`의 주문월.
- 포함·제외 상태: `Cancelled`, `Returned` 제외.
- 분자·분모: 분자만 존재하며 품목별 `sale_price-cost` 합계.
- 단위: 원천 데이터 통화 금액.
- 반올림: CSV 소수 둘째 자리, 사업 문서 정수.
- 한계: 물류비·결제수수료·마케팅비·인건비 컬럼이 없어 영업이익이 아님.

## 5. 마진율

- 사업 정의: 순매출 중 상품 원가 차감 후 마진이 차지하는 비율.
- SQL 정의: `SAFE_DIVIDE(margin, net_revenue)`.
- 날짜 기준: `orders.created_at`의 주문월.
- 포함·제외 상태: 분자와 분모 모두 `Cancelled`, `Returned` 제외.
- 분자·분모: 마진 / 순매출.
- 단위: 비율 `%`.
- 반올림: CSV 소수 여섯째 자리, 사업 문서 소수 첫째 자리 `%`.
- 한계: 상품 원가 이외 비용이 `0개 컬럼`이므로 영업이익률이 아님.

## 6. 재구매율

- 사업 정의: 유효 주문을 2건 이상 보유한 구매고객의 비율.
- SQL 정의: 고객별 유효 주문수를 집계한 뒤 `COUNTIF(order_count >= 2) / COUNT(*)`.
- 날짜 기준: `orders.created_at <= 2026-08-07`.
- 포함·제외 상태: `Cancelled`, `Returned` 제외.
- 분자·분모: 유효 주문 2건 이상 고객 / 유효 주문 1건 이상 고객.
- 단위: 비율 `%`.
- 반올림: 사업 문서 소수 첫째 자리 `%`.
- 한계: 합성 데이터 전체 재구매율 `37.4%`를 실제 기업 기준값으로 사용하지 않음.

## 7. 코호트 리텐션

- 사업 정의: 첫 유효 구매월 코호트 중 M+N에 다시 구매한 고객 비율.
- SQL 정의: `COUNT(DISTINCT active_user_id) / cohort_size`, M+1~M+12.
- 날짜 기준: 첫 구매와 재구매 모두 `orders.created_at`; 기준일 `2026-08-07`.
- 포함·제외 상태: `Cancelled`, `Returned` 제외.
- 분자·분모: M+N 활성 고객 / 첫 구매월 코호트 고객.
- 단위: 비율 `%`.
- 반올림: CSV 소수 여섯째 자리, 사업 문서 소수 첫째 자리 `%`.
- 한계: `444셀` 중 `90셀`은 관측 미완료로 NULL이며, M+1 `2.3%`에서 M+12 `1.8%`로 감쇠가 약해 상대 비교에만 사용함.
